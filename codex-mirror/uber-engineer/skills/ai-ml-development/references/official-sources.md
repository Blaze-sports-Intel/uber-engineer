1. Official platform docs (Anthropic for Claude Code, OpenAI for Codex).
2. Official Agent Skills specification.
3. Official repositories maintained by Anthropic or OpenAI.
4. Official docs for the discipline-specific frameworks above.
5. Community examples — labeled non-authoritative.

If official docs conflict with anything in this skill, follow the official docs and update this
